# S-DES and RSA Cryptography Implementation

A C++ project implementing two fundamental cryptographic algorithms: Simplified Data Encryption Standard (S-DES) and RSA Public-Key Encryption.

## Features

* S-DES key generation
* S-DES encryption and decryption
* RSA public and private key generation
* RSA encryption and decryption
* Modular arithmetic and number theory operations
* Command-line interface for user interaction

## Technologies

* C++
* Object-Oriented Programming
* Cryptography Algorithms
* Modular Arithmetic

## Learning Outcomes

This project demonstrates core cybersecurity and cryptography concepts, including symmetric encryption, asymmetric encryption, key management, and secure data transmission principles.
